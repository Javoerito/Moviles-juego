# Entrega del taller: mensaje para Teams

Copia y pega esto en el canal (cambia solo la línea 2 cuando tengas tu página de itch.io):

```
🎮 ViboLínea — Equipo [nombre del equipo]

* Link Juego (GitHub Pages): https://javoerito.github.io/Moviles-juego/juego/
* Link Perfil de juego (itch.io): https://TU_USUARIO.itch.io/viblinea
* Link Página web (landing): https://javoerito.github.io/Moviles-juego/

Código: https://github.com/Javoerito/Moviles-juego

🏆 Mención de honor: CI/CD con GitHub Actions + butler
   push a main → publica solo en itch.io (archivo .github/workflows/itch.yml)
```

Si no lograron el CI/CD, borra el último bloque.

## Checklist antes de enviar

- [ ] La landing abre y el botón JUGAR lleva al juego.
- [ ] El juego carga con la demo y con una canción propia.
- [ ] Página de itch.io creada y publicada (no en borrador). Ver `itch/PERFIL-ITCH.md`.
- [ ] Enlace de itch.io pegado en la landing (`const ITCH_URL`) y en este mensaje.
- [ ] Foto de la RAM de la intro: autoría confirmada o reemplazada (ver README).
- [ ] Nombres reales del equipo en el Muro de Honor.
